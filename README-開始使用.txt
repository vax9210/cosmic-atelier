Cosmic Atelier × Pages CMS 第一階段

1. 請先備份目前 GitHub Repository。
2. 將 index.html、.pages.yml、data/site.json、data/sources.json 上傳到 cosmic-atelier 的根目錄，取代原 index.html。
3. 注意：請保留原本的 sitemap.xml 和 google 驗證檔！不要刪除。
4. 等 GitHub Pages 重新部署。
5. 開啟 https://app.pagescms.org/ 使用 GitHub 登入；授權 GitHub App 存取 cosmic-atelier。
6. 在 Pages CMS 選擇 vax9210/cosmic-atelier 的 main 分支，就可看到首頁文字設定及天文期刊與來源。
7. 儲存更改後等 GitHub Pages 自動重新部署即可。

注意：這是第一階段可用版，提供首頁文字和文獻來源編輯。完整獨立文章發布及 SEO 多頁文章系統尚未整合。
本地直接雙擊 index.html 時，瀏覽器可能禁止讀取 JSON（file://）；請用 GitHub Pages 網址測試。
圖片可透過 CMS 上傳至 media，但目前首頁沒有圖片挑選欄位。
